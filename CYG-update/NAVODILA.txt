CYG – posodobitev izgleda in treninga, 24. 9. 2026

KAJ JE V PAKETU
- src/: posodobljena izvorna koda, brez stare podvojene mape src/src.
- public/: slikovna sredstva, tudi novi fotografiji za Home in Workout.
- CYG-update/: navodila in poročilo preverjanja.

NAMESTITEV V C:\bodypilot
1. ZIP shrani v C:\bodypilot z imenom CYG-UPDATE-2026-09-24.zip.
2. Če v terminalu teče npm run dev, ga ustavi s Ctrl+C.
3. V PowerShell prilepi naslednje ukaze po vrsti:

cd C:\bodypilot
$cygBackup = "..\bodypilot-backup-$(Get-Date -Format 'yyyyMMdd-HHmmss')"
New-Item -ItemType Directory -Path $cygBackup | Out-Null
Copy-Item .\src "$cygBackup\src" -Recurse
if (Test-Path .\public) { Copy-Item .\public "$cygBackup\public" -Recurse }
Expand-Archive -Path .\CYG-UPDATE-2026-09-24.zip -DestinationPath . -Force
npm.cmd run build

Pomembno: ZIP razširi v C:\bodypilot, ne v C:\bodypilot\src.
Pravi datoteki sta C:\bodypilot\src\app\page.tsx in
C:\bodypilot\public\cyg\hero-athlete.png.
Paket ne vsebuje ali spreminja .env.local, API ključev ali podatkov uporabnikov.
Ni treba znova izvajati SQL poizvedb. Uporabi svoj obstoječi tsconfig.json,
ki že izključuje staro podvojeno mapo src/src.

LOKALNI OGLED
Po uspešnem buildu:

npm.cmd run dev

Odpri naslov Local, ki ga izpiše terminal. Ne zaganjaj drugega dev strežnika,
če prvi že teče. Osveži stran s Ctrl+F5.

KAJ PREVERI
- Home: temno modra fotografija, bele kartice, krožni prikaz kalorij.
- Nutrition: krožni prikaz, makri, obroki na odpiranje, zgodovina po datumih.
- Workout: tedenski izbor, fotografija treninga, dostop do vaj in zgodovine zgoraj.
- PPL: Push, Pull, Legs, Push B, Pull B, Legs B v pravilnem zaporedju.
  Ohranjeni so izbrani dnevi; po dopolnitvi se ponovno kronološko razvrstijo.
- Aktivni trening: večji časovnik, počitek, jasna tabela serij.
- Air Bike/Fan Bike: čas in razdalja, ohranjen običajen seznam vaj.
- History: razširi trening, klikni ime vaje; zgodovina vaje privzeto zajema vsa leta.
  Meni s tremi pikami: urejanje, preimenovanje, opomba, kalorije, deljenje, brisanje.
- Zaključek: pregled serij, volumna in ocene porabe; možno urejanje ali zavrženje.
- Progress: dejanski trend teže, moč, tedenska rednost in dosežki.
- More: skupine nastavitev in 8 kategorij dosežkov z napredovanjem do naslednjega mejnika.
- More > Display & Appearance: izberi Light ali Dark in pritisni Save settings.

PODATKI IN OMEJITVE
Obstoječi podatki ostanejo v dosedanji lokalni/oblačni shrambi. Posnetki za prikaz
vsebujejo izključno vzorčne podatke; ti niso vključeni v aplikacijo.
Trajanje običajnih treningov ostane dejansko. Stari Lyfta uvozi brez zanesljivega
trajanja so označeni s ~ in imajo oceno iz zabeleženih serij, ne enotnih 60 minut.
Ocene kalorij ostanejo približne.
Prijave in sinhronizacije s tvojim dejanskim Supabase računom v tem okolju nisem
preverjal, ker tukaj ni tvojih produkcijskih nastavitev. Obstoječe povezave so ohranjene.
Ta posodobitev ne dodaja ilustracij za vseh 600 vaj; ohranjene so obstoječe ilustracije.
